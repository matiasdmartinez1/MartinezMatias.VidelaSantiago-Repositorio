# MartinezMatias.VidelaSantiago-Repositorio
Martínez Matías, Videla Santiago Examen domiciliario de R.
En este repositorio presentamos nuestro examen domiciliario de R, dividido en tres ejercicios.
En la carpeta **analisis_datos** trabajamos con las bases de bicicleteros y ciclovías. En **análisis_econométrico** utilizamos la base Gapminder para realizar regresiones y analizar correlaciones entre países. Por último, en **simulación** realizamos una simulación de ataques del juego TEG para estimar la probabilidad de victoria del atacante.
Cada ejercicio tiene su propio script de R y las bases de datos utilizadas están guardadas en las carpetas correspondientes. En el ejercicio de simulación, las funciones están en un archivo separado y se cargan desde el script principal con "source()"
También incluimos un informe en PDF donde explicamos los procedimientos.
